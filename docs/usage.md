# Inspect a CircleCI build

Open a build from **Recent Builds** or a project's build list. From its details, you can search
step logs, inspect reported test failures, and save artifacts.

## Find text in a step log

1. Tap a build step to open its log.
2. When **Find in log** appears, tap it and type the text you want to find. The search matches
   literal text regardless of case and covers only the log shown for that step.
3. Use **Previous** and **Next** to move between matches, or **Close** to clear the search.

## Read test failures

Tap **Test Results** on the build details screen. The screen lists the failures CircleCI
reported for that job. Tap **Show failure message** on a result to read its details.

## Save an artifact

1. Open the build details overflow menu and select **Artifacts**.
2. Tap an artifact and choose where to save it in the Android file picker.
3. Wait for **Artifact saved.** before opening the file from the location you chose.

See [FAQ and troubleshooting](faq.md) for test results and artifact errors.
